# Task 11 — Ask Athena

## 구현
- DB 스키마 및 마이그레이션 (`packages/db/src/schema/assistant.ts`, `0008_chat.sql`)
  - `chat_threads`: 웹사이트·작성자별 대화 스레드(`runningSince`로 동시 실행 잠금, 소프트 삭제 `deletedAt`).
  - `chat_messages`: 메시지(`role`, `content`, 텍스트 첨부 `attachments`, 실행된 도구 요약 `toolCalls`, `provider`, `simulated`, 상태 `complete | stopped`).
- `core/assistant`
  - `threads.ts`: 스레드 생성·조회·목록·제목 수정·소프트 삭제, `claimRun`/`finishRun`/`releaseRun`을 통한 스레드당 단일 응답 실행 선점(3분 타임아웃 후 죽은 실행 회수), `historyForModel`을 통한 최근 대화·첨부(최신 턴만 전체 본문, 이전 턴은 2,000자 미리보기) 구성.
  - `tools.ts`: 워크스페이스 권한(`prompts:read`)을 검증하는 읽기 전용 도구 5종(`get_visibility_metrics`, `compare_competitors`, `search_answers`, `top_sources`, `find_content_opportunities`), `zod/v4` 입력 JSON 스키마 생성.
  - `prompt.ts`: 브랜드명·도메인 제어문자 정제(한 줄 상한) 및 도구 결과·첨부파일을 비신뢰 데이터로 취급하는 시스템 프롬프트 빌더.
- `llm/chat`
  - `anthropic.ts`: 공식 Anthropic SDK(`messages.stream` + `finalMessage`) 기반 스트리밍 도구 루프.
  - `openai-compatible.ts`: OpenAI/xAI/DeepSeek 호환 함수 호출 루프 및 청크 스트리밍.
  - `simulated.ts`: 개발 환경(`LLM_SIMULATED_PROVIDER=true`, 비운영 전용)에서 실제 워크스페이스 도구 결과를 실행해 표·목록·링크로 응답하는 시뮬레이터.
  - `index.ts`: 환경 키 우선순위에 따른 프로바이더 선택 및 첫 바이트 방출 전 실패 시 다음 프로바이더(개발 시 시뮬레이터 포함) 폴백.
- 웹 (`apps/web`)
  - `lib/request.ts`, `lib/limits.ts`, `lib/assistant.ts`, `lib/ask-run.ts`: 동일 출처(CSRF) 및 JSON 크기(512KB) 검증, 사용자별 레이트리밋(새 스레드 30회/10분, 답변 20회/10분), Google Search Console 연결 시 `search_console_queries` 도구 동적 주입, NDJSON 스트리밍 및 중단(Abort) 시 부분 응답 저장/빈 응답 해제.
  - `/api/athena/chat`: 새 스레드 생성(`201`) 및 기존 스레드 후속 질문·답변 NDJSON 스트리밍.
  - `/home` (`ask-home.tsx`), `/chat` (`ath-chat.tsx`), `components/ask/*`: 인사 헤딩, 컴포저, 추천 칩 4종, 텍스트 파일 첨부(TXT/MD/CSV/TSV/JSON, 최대 3개·10만 자, 드래그앤드롭), 커넥터 컨텍스트 바(Workspace analytics + Google Search Console 토글/연결 링크), 안전한 Markdown 렌더러(`safeHref`로 `javascript:`·외부 프로토콜 상대 URL 차단), 스레드 히스토리·제목 변경·삭제.
  - 고아 정리: `lib/data.ts`의 구 데모 헬퍼(`getDashboardData`, `getResponses`, `demoSources` 재수출) 제거.
