# Task 6 — 분석 파이프라인 (구조화 추출 + 메트릭 집계)

## 구현
- `packages/core/src/extract`: 유니코드 단어 경계·대소문자 무시 엔티티 매칭(이름·도메인·단일 단어 브랜드의 도메인 라벨, URL 내부 제외, 겹침 병합), 포지션(번호/불릿 목록 순위 → 없으면 첫 언급 순서), 엔티티별 감성(문장 내 가장 가까운 언급에 단서 귀속, 3단어 내 부정어 반전, 긍·부정 동시 → mixed), 속성 관측(엔티티 귀속·부정 처리), 인용(마크다운+일반 URL, 후행 구두점·괄호 정리, 중복 제거, 순위), 쇼핑 카드(가격+판매처 목록, 구독/요금제 표현 제외)
- `packages/core/src/analytics/visibility.ts`: SQL 집계 — 멘션률·인용률·평균 포지션·SOV(응답당 엔티티 1회) 누적 + 일별(웹사이트 타임존 버킷) + 모델별 + 엔티티별 점유율, 필터(기간·모델·토픽·페르소나·위치·태그·프롬프트·유형), 시뮬레이션 비중
- `packages/jobs` `reanalyzeResponses`: 저장된 답변 재추출(경쟁사·속성 변경/추출기 개선 시), 프로바이더 인용은 유지 + 운영 스크립트 `npm run reanalyze`
- 수집기: 속성 관측에 경쟁사 귀속 저장
