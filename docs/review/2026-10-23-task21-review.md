## 1. 구현 내역 요약

1. **API 키 인증 및 토큰 버킷 레이트리미터 (`apps/web/src/lib/api-key.ts`)**:
   - `Authorization: Bearer ath_…` 및 `X-API-Key: ath_…` 헤더 이중 지원.
   - 키 해시(`SHA-256`) 기반 인메모리 토큰 버킷 레이트리미터(60 req/min/key, 최대 10,000 버킷 메모리 상한 및 유휴 버킷 자동 정리) + `429 Too Many Requests` 응답 시 `Retry-After: 5`, `X-RateLimit-Limit: 60`, `X-RateLimit-Remaining: 0` 표준 헤더 반환.
   - `verifyApiKey`를 통한 상수 시간(`timingSafeEqual`) 해시 검증 및 `last_used_at` 자동 갱신.
2. **공개 REST API `/api/v1/*` 전체 엔드포인트 완성**:
   - `/api/v1/validate-api-key` (`GET`): 키 유효성 및 테넌트 `organizationId` 반환.
   - `/api/v1/websites` (`GET`, `POST`): 조직 내 브랜드 목록 조회 및 프로비저닝.
   - `/api/v1/prompts` (`GET`, `POST`): 웹사이트 잠금(`lockWebsite`), 요금제별 프롬프트 한도 검증(`promptLimitFor`), 대소문자 무시 중복 방지, 토픽 자동 생성/연결을 포함한 프롬프트 등록 API.
   - `/api/v1/basics/[entity]` (`GET`): `topics`, `competitors`, `personas`, `locations`, `tags`, `schedules` 6종 엔티티 전체 지원.
   - `/api/v1/metrics/[kind]` (`GET`): `share-of-voice`, `mention-rate`, `citation-rate`, `position` (`cumulative` / `over-time`).
   - `/api/v1/sources` (`GET`), `/api/v1/responses` (`GET`), `/api/v1/response-streaming` (`POST`) & `/api/v1/response-streaming/status` (`GET`), `/api/v1/content` (`GET`, `POST`).
   - `/api/v1/kb` (`GET`, `POST`): Knowledge Base 필러(`kb_pillars`), 브랜드 팩트(`kb_facts`), Oracle 정확도 감사(`oracle_findings`) 조회 및 생성.
   - `/api/v1/billing/credits` (`GET`): `?scope=all|organization|website|group` 필터링, 3-Scope 크레딧 요약(`summary`), 원장(`ledger`), 인보이스(`invoices`) 반환.
   - `/api/v1/teams` (`GET`): 조직 멤버, 포트폴리오 그룹, 추적 웹사이트, 커스텀 RBAC 역할 조회.
   - `/api/v1/connectors/[provider]` (`GET`): Google Looker Studio (`looker-studio`, 필드 스키마 + 일별 시계열 행) 및 Microsoft Power BI (`power-bi`, OData JSON 및 `format=csv` 스트림) 전용 BI 커넥터 피드.
3. **Athenum MCP 서버 (`apps/mcp/src/index.ts`)**:
   - 14개 MCP 도구(`list_websites`, `list_prompts`, `get_basics`, `get_metrics`, `get_sources`, `search_responses`, `get_knowledge_base`, `create_kb_fact`, `create_content`, `get_billing_credits`, `get_teams`, `get_bi_connector_feed`, `start_collection`, `get_collection_status`) 등록 및 `/api/v1/*` 연동.
4. **API·MCP·BI 커넥터 설정 UI (`apps/web/src/app/(app)/settings/api/page.tsx`)**:
   - API 키 발급/폐기, `/api/v1` 전체 레퍼런스 테이블, Claude/ChatGPT MCP 설정 JSON 스니펫, Looker Studio / Power BI 커넥터 피드 URL 및 다운로드 링크 제공.

## 2. 적대적 검토(Adversarial Review) 및 수정 사항

| # | 발견된 취약점 / 엣지 케이스 | 심각도 | 수정 내용 |
|---|---|---|---|
| 1 | `POST /api/v1/websites`에서 `body.groupId`가 요청 API 키의 `organizationId` 소속인지 검증하지 않아 타 테넌트 그룹에 웹사이트를 연결할 수 있던 취약점 | **High (Tenant Isolation)** | `groups` 테이블에서 `id = body.groupId AND organization_id = ctx.organizationId AND deleted_at IS NULL` 조건을 검증하고 미일치 시 `404` 반환하도록 수정 |

| 3 | `POST /api/v1/prompts`가 `501 Not Implemented` 스텁으로 남아 있어 API를 통한 프롬프트 등록 불가 및 동시 요청 시 한도 우회 위험 | **Medium (Completeness / Concurrency)** | `db.transaction` 내부에서 `lockWebsite` 획득 후 `promptLimitFor` 한도 검사, 중복 프롬프트 차단, `topicName` 자동 연결을 수행하도록 구현 |
| 4 | `GET /api/v1/connectors/{looker-studio|power-bi}?format=csv`에서 브랜드명/도메인이 `=`, `+`, `-`, `@`로 시작할 경우 Excel/Power BI에서 CSV 수식 인젝션 발생 가능 | **Medium (CSV Formula Injection)** | `safeCsvCell` 헬퍼를 통해 선행 수식 문자(`=`, `+`, `-`, `@`) 앞에 작은따옴표(`'`)를 프리픽스하고 내부 따옴표를 이스케이프 처리 |
