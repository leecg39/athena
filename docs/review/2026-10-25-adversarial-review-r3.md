## 2. 검증 증거 (2026-10-25)

- **단위·통합 테스트:** `npx vitest run` → 56개 파일, 317개 테스트 통과(exit 0).
- **타입 체크:** `npx turbo run typecheck --force` → 11/11 성공(캐시 0, exit 0).
- **빌드:** `turbo run build --filter=@athena/web` exit 0. `@athena/marketing`·`@athena/docs` 빌드 exit 0이며, 결과물에 `localhost:3000`이나 허위 문구가 없다.
- **브라우저 E2E(격리 DB `athena_r3`, 포트 3300):**
  - 리포트: 조회 시 시드 0개. 채널이 없으면 "Nothing was sent"이고 `lastSentAt`은 그대로다. 공개 리포트 값이 SQL과 일치한다(답변 35건, 멘션률 74.3%, 인용률 0%, 시뮬레이션 100% 경고). `/report/demo-Nike`는 404, PDF는 200이고 값이 없으면 "-"로 나온다.
  - 피치: 질문 2개 × 제공자 2개 = 4크레딧을 예약했고, xAI 403으로 실패한 2건은 환불됐다(원장 -4/+2). 공개 뷰에 시뮬레이션 표시와 답변 원문 발췌가 나온다.
  - 그룹: 98건, 59.2%, 0.0%로 SQL과 일치한다.
  - 과금: 미설정 시 비활성이다. 테스트 모드에서는 status `test`, 금액 0, "not charged"로 기록된다.
  - 관측: 시드가 없고 이 조직 이벤트만 보인다.
